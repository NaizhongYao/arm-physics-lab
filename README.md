# 机械臂虚拟试验台 · 网页版（概念验证）

一个可在浏览器里操控的 4 自由度机械臂物理仿真。

**打开网址即可操作，不需要安装任何东西。** 推荐 Chrome 或 Edge。

## 这是什么

- 一个 4 自由度机械臂（底座旋转 / 肩部抬起 / 肘部弯曲 / 夹爪开合）的刚体物理仿真
- 物理引擎：Godot 4.6.3 + Jolt Physics，240 Hz 定步长
- 操作：A / D 底座，W / S 肩部，R / F 肘部，Q / E 夹爪，空格暂停，右键拖动转视角，滚轮缩放
- 桌面上的方块是自由刚体：有重力、有摩擦，夹不住会掉，夹歪了会滑

## 请务必注意

**这是物理仿真，不是实物能力证明。** 仿真里的摩擦系数、传动效率、各零件质量、舵机扭矩上限都是假设值，尚未用实物标定。仿真里能抓起来，不代表这台机械臂的实物能抓起来。

本版本是**概念验证**：目的是验证「能否把一个 Godot 仿真导出成网页并分享给别人操控」。界面仍是面向工程调试的版本，尚未针对普通用户或触屏优化。

## 与本地版本的差异

为了把网页体积从约 130 MB 压到约 15 MB，导出的资源包里**排除了转盘视觉模型 `yaw.glb`**（89 MB）。该部件在网页版显示为占位方块。

**物理完全一致**：碰撞形状、质量、惯量、关节限位、扭矩上限都由代码定义，与视觉模型无关。所以网页版的物理和本地版是同一套参数、同一个求解器。
